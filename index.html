Settings & Security

Admin · edit app text

Customize dashboard headings and descriptions. Your changes are saved in this browser’s encrypted app data.

Admin controls are protected by your passcode. The app name and sample-data notices stay fixed so the app remains clear about what is real and what is demo content.

Passcode & privacy

Your dashboard is encrypted with AES-GCM. The passcode is never stored directly and is used to derive the encryption key. If you forget it, encrypted data cannot be recovered.

Encrypted device transfer

Offline setup: copy this app folder to the other device by USB and open index.html. On this device, export an encrypted backup and copy that file over too. On the other device, unlock or set up its passcode, enter the exporting device’s passcode below, then choose the backup file. This transfers a snapshot; it does not sync changes automatically. Export/import again to move newer data. This app cannot enforce a two-device limit.
